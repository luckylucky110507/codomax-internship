# Day 4 - Pandas 

## Objective
Learn how to load a dataset using Pandas and perform basic exploratory data analysis (EDA).

## Tools Used
- Python
- Jupyter Notebook
- Pandas

## Dataset
Student Scores Dataset

## Tasks Performed

- Imported the Pandas library
- Loaded the CSV dataset using `pd.read_csv()`
- Displayed the first 5 rows using `head()`
- Viewed all column names
- Checked dataset shape
- Explored dataset information using `info()`
- Generated summary statistics using `describe()`
- Checked missing values
- Verified duplicate records
- Examined data types
- Displayed the last 5 rows using `tail()`

## Key Observations

- Dataset contains **2000 rows** and **17 columns**
- No missing values found
- No duplicate records found
- Dataset contains integer, boolean, and object data types
- Basic statistical summary generated successfully

## Learning Outcome

- Working with Pandas DataFrames
- Reading CSV files
- Exploring dataset structure
- Understanding dataset statistics
- Inspecting missing values and duplicates
